# 화면 구성과 이동

로그인부터 모든 화면과 버튼이 어디로 이어지는지 정리한 문서다.
칸(항목) 설명은 [데이터 구조](data-model.md) 를 본다.

## 1. 화면 목록

| 화면 | 주소 | 로그인 |
| --- | --- | --- |
| 로그인 | `/login` | 필요 없음 |
| 분실물 대장 | `/found` | 필요 |
| 분실물 접수 | `/found/new` | 필요 |
| 분실물 상세 | `/found/:관리번호` | 필요 |
| 분실물 수정 | `/found/:관리번호/edit` | 필요 |
| 반환 처리 | `/found/:관리번호/return` | 필요 |
| 분실신고 대장 | `/lost` | 필요 |
| 분실신고 접수 | `/lost/new` | 필요 |
| 분실신고 상세 | `/lost/:관리번호` | 필요 |
| 분실신고 수정 | `/lost/:관리번호/edit` | 필요 |
| 분실물 찾아 연결 | `/lost/:관리번호/match` | 필요 |
| 설정값 변경 | `/settings` | 필요 |

`/` 로 들어오면 분실물 대장으로 보낸다.

## 2. 화면 이동 지도

```
[로그인]
   │ 로그인 성공
   ▼
┌──────────────────────── 왼쪽 메뉴 (로그인 후 모든 화면 공통) ────────────────────────┐
│                                                                                      │
│  분실물 대장 ─────┬─ [+ 분실물 접수] ─→ [분실물 접수] ─ 등록 ─→ [분실물 상세]        │
│                   │                                   └ 취소 ─→ [분실물 대장]        │
│                   └─ 줄 누름 ─→ [분실물 상세] ─┬─ [수정] ─→ [분실물 수정]            │
│                                                │              ├ 저장 ─→ [상세]       │
│                                                │              ├ 삭제 ─→ [대장]       │
│                                                │              └ 취소 ─→ [상세]       │
│                                                ├─ [반환 처리] ─→ [반환 처리]         │
│                                                │              ├ 처리 ─→ [상세]       │
│                                                │              └ 취소 ─→ [상세]       │
│                                                └─ [목록] ─→ [분실물 대장]            │
│                                                                                      │
│  분실신고 대장 ───┬─ [+ 분실 신고] ─→ [분실신고 접수] ─ 등록 ─→ [분실신고 상세]      │
│                   └─ 줄 누름 ─→ [분실신고 상세] ─┬─ [수정] ─→ [분실신고 수정]        │
│                                                  ├─ [분실물 찾기] ─→ [찾아 연결]     │
│                                                  │                ├ 연결 ─→ [상세]   │
│                                                  │                └ 취소 ─→ [상세]   │
│                                                  └─ [목록] ─→ [분실신고 대장]        │
│                                                                                      │
│  설정값 변경 ─── 다섯 가지 설정을 한 화면에서 고친다                                 │
│                                                                                      │
└──────────────────────────────────────────────────────────────────────────────────────┘
   │ 로그아웃 (오른쪽 위) 또는 로그인 시간 만료
   ▼
[로그인]
```

## 3. 화면별 구성과 버튼

### 로그인 `/login`

아이디, 비밀번호, 로그인 버튼만 있는 가운데 정렬 화면이다. 왼쪽 메뉴는 없다.

| 버튼 | 하는 일 |
| --- | --- |
| 로그인 | 성공하면 분실물 대장으로 간다. 실패하면 입력칸 아래에 문구를 보여주고 그대로 머문다 |

### 공통 틀 (로그인 후 모든 화면)

왼쪽에 메뉴, 오른쪽 위에 로그인한 사람 이름과 로그아웃 버튼을 둔다.

| 메뉴 | 가는 곳 |
| --- | --- |
| 분실물 대장 | `/found` |
| 분실신고 대장 | `/lost` |
| 설정값 변경 | `/settings` |

| 버튼 | 하는 일 |
| --- | --- |
| 로그아웃 | 저장된 로그인 정보를 지우고 로그인 화면으로 간다 |

### 분실물 대장 `/found`

검색칸, 필터, 건수, 표, 쪽번호로 이루어진다.
표에는 관리번호, 사진, 물품명과 습득장소, 물품 구분, 접수일, 습득일, 처리상태, 접수담당자를 보여준다.

| 버튼 | 하는 일 |
| --- | --- |
| 표의 줄 | 그 건의 분실물 상세로 간다 |
| + 분실물 접수 | 분실물 접수 화면으로 간다 |
| 필터 | 물품 구분, 처리상태, 습득장소, 보관장소, 기한 경과 여부로 거른다 |
| 엑셀 내보내기 | 지금 걸러진 목록을 파일로 내려받는다. 화면은 그대로 |
| 쪽번호 | 같은 화면에서 다음 쪽을 보여준다 |

### 분실물 접수 `/found/new`

관리번호는 자동으로 채워 보여주고 고칠 수 없다.
사진, 기본 정보, 물품 정보, 습득 정보, 보관 정보, 습득자 정보, 분실자 정보, 관리 정보 차례로 둔다.

| 버튼 | 하는 일 |
| --- | --- |
| 사진 칸 | 파일을 고르면 바로 올리고 자리에 보여준다. 다섯 장까지 |
| 사진의 삭제 | 그 장을 뺀다. 저장 전에도 뺄 수 있다 |
| 등록 | 저장하고 방금 만든 건의 상세로 간다. 빠진 필수 항목이 있으면 저장하지 않고 문구를 보여준다 |
| 취소 | 저장하지 않고 분실물 대장으로 간다 |

### 분실물 상세 `/found/:관리번호`

접수 화면과 같은 배치로 값만 보여준다. 반환이 끝난 건이면 반환 정보도 함께 보여준다.

| 버튼 | 하는 일 |
| --- | --- |
| 목록 | 분실물 대장으로 간다 |
| 수정 | 분실물 수정 화면으로 간다 |
| 반환 처리 | 반환 처리 화면으로 간다. 이미 반환된 건이면 버튼 대신 반환 정보를 보여준다 |

### 분실물 수정 `/found/:관리번호/edit`

접수 화면과 같은 배치에 저장된 값이 채워져 있다. 관리번호는 고칠 수 없다.

| 버튼 | 하는 일 |
| --- | --- |
| 저장 | 바뀐 항목만 보내고 상세로 간다 |
| 삭제 | 한 번 더 묻고, 예를 고르면 지운 뒤 분실물 대장으로 간다 |
| 취소 | 고친 내용을 버리고 상세로 간다 |

### 반환 처리 `/found/:관리번호/return`

위쪽에 어떤 물건인지 간단히 보여주고, 아래에 수령자 학번, 수령자 이름, 수령일,
확인 방법, 확인담당자를 입력받는다. 수령일은 오늘, 확인담당자는 로그인한 사람으로 미리 채운다.

| 버튼 | 하는 일 |
| --- | --- |
| 반환 처리 | 반환 정보를 저장하면서 처리상태를 본인반환으로, 처리일을 수령일로 함께 바꾸고 상세로 간다 |
| 취소 | 저장하지 않고 상세로 간다 |

### 분실신고 대장 `/lost`

표에는 관리번호, 물품 구분, 물품명, 신고자, 연락처, 접수일, 분실일, 처리상태, 접수담당자를 보여준다.
나머지는 분실물 대장과 같다.

| 버튼 | 하는 일 |
| --- | --- |
| 표의 줄 | 그 건의 분실신고 상세로 간다 |
| + 분실 신고 | 분실신고 접수 화면으로 간다 |

### 분실신고 접수 `/lost/new` · 수정 `/lost/:관리번호/edit`

물품 정보, 분실 정보, 신고자 정보, 관리 정보를 입력받는다. 사진은 쓰지 않는다.
버튼 동작은 분실물 접수·수정과 같다.

### 분실신고 상세 `/lost/:관리번호`

연결된 분실물이 있으면 그 관리번호와 물품명을 함께 보여주고, 누르면 그 분실물 상세로 간다.

| 버튼 | 하는 일 |
| --- | --- |
| 목록 | 분실신고 대장으로 간다 |
| 수정 | 분실신고 수정 화면으로 간다 |
| 분실물 찾기 | 분실물 찾아 연결 화면으로 간다. 이미 연결됐으면 연결 해제 버튼을 보여준다 |

### 분실물 찾아 연결 `/lost/:관리번호/match`

위에 신고 내용을 보여주고, 아래에 분실물 목록을 검색해서 고르게 한다.
처음 열 때 신고의 물품 구분과 분실일 전후로 걸러 둔다.

| 버튼 | 하는 일 |
| --- | --- |
| 목록의 선택 | 그 분실물을 고른 것으로 표시한다. 화면은 그대로 |
| 연결 | 고른 분실물을 신고에 연결하고 처리상태를 처리완료로 바꾼 뒤 분실신고 상세로 간다 |
| 취소 | 연결하지 않고 분실신고 상세로 간다 |

### 설정값 변경 `/settings`

다섯 가지 설정을 한 화면에 세로로 둔다.
물품 구분, 분실물 처리상태, 분실신고 처리상태, 건물, 보관장소 차례다.

| 버튼 | 하는 일 |
| --- | --- |
| 저장 | 그 줄을 고친다. 화면은 그대로 있고 목록만 새로 받아온다 |
| 사용중지 | 한 번 더 묻고 그 줄을 사용중지로 바꾼다. 새 등록 목록에서 빠지고 과거 기록은 그대로 남는다 |
| 사용재개 | 다시 쓰도록 되돌린다 |
| 추가 | 맨 아래 줄에 적은 값으로 새 항목을 만든다 |
| 목록으로 | 분실물 대장으로 간다 |

## 4. 주요 흐름

### 접수

1. 분실물 대장에서 **+ 분실물 접수**
2. 사진을 올리고 항목을 채운다
3. **등록** → 저장된 건의 상세가 열린다
4. 잘못 적었으면 **수정**, 다 됐으면 **목록**

### 반환

1. 분실물 상세에서 **반환 처리**
2. 수령자와 확인 정보를 채운다
3. **반환 처리** → 처리상태가 본인반환으로 바뀌고 상세로 돌아온다
4. 상세에 반환 정보가 함께 보인다

### 분실신고와 분실물 연결

1. 분실신고 상세에서 **분실물 찾기**
2. 걸러진 분실물 목록에서 고른다
3. **연결** → 신고의 처리상태가 처리완료로 바뀌고 상세로 돌아온다
4. 물건을 돌려줄 때는 연결된 분실물 상세로 가서 반환 처리를 한다

### 설정 변경

1. 설정값 변경에서 값을 고치고 **저장**
2. 바뀐 이름은 기존 대장에도 바로 반영된다
3. 더 안 쓰는 항목은 **사용중지**. 과거 기록의 이름은 그대로 남는다

## 5. 입력하는 동안 바뀌는 것

| 무엇을 하면 | 어떻게 바뀌나 |
| --- | --- |
| 물품 구분을 고르면 | 보관만료일과 만료 시 조치 방법이 자동으로 채워진다 |
| 습득일을 바꾸면 | 보관만료일을 다시 계산한다 |
| 습득자 구분을 학생으로 고르면 | 번호 칸 이름이 학번이 된다 |
| 습득자 구분을 교직원으로 고르면 | 번호 칸 이름이 교직원번호가 된다 |
| 습득자 구분을 외부인이나 기타로 고르면 | 번호 칸을 숨긴다 |
| 사진을 다섯 장 올리면 | 추가 버튼을 더 누를 수 없게 한다 |
| 저장을 누르면 | 저장이 끝날 때까지 버튼을 누를 수 없게 한다 |
| 수정에서 처리상태를 본인반환으로 바꾸면 | 반환 정보가 비어 있다고 알리고 반환 처리 화면을 권한다 |

## 6. 공통 규칙

| 상황 | 화면 |
| --- | --- |
| 자료를 받아오는 중 | 가운데에 "불러오는 중입니다" |
| 받아오지 못함 | 까닭과 **다시 시도** 버튼. 상세 화면이면 **목록으로** 도 함께 |
| 없는 관리번호 | "요청한 데이터를 찾을 수 없습니다" 와 **목록으로** |
| 로그인 시간 만료 | 어느 화면에 있든 로그인 화면으로 보낸다 |
| 권한이 없음 | 그 자리에 까닭을 보여주고 화면은 그대로 둔다 |
| 필수 항목이 빔 | 저장하지 않고 버튼 옆에 어떤 항목인지 보여준다 |
| 지우기 | 반드시 한 번 더 묻는다 |

## 7. 정해야 할 것

| 물음 | 지금 문서의 가정 |
| --- | --- |
| 왼쪽 메뉴로 갈지, 지금처럼 위쪽 탭으로 갈지 | 화면이 늘어나므로 왼쪽 메뉴로 잡았다 |
| 처리완료 내역을 따로 둘지 | 대장의 처리상태 필터로 보는 것으로 잡았다 |
| 통계 현황 화면 | 넣지 않았다. 필요하면 메뉴를 하나 더 둔다 |
| 알림 | 넣지 않았다. 보관기한이 지난 건을 알리는 용도라면 대장의 필터로 대신할 수 있다 |
| 분실신고 사진 | 쓰지 않는 것으로 잡았다 |
| 연결과 반환을 한 번에 할지 | 따로 두었다. 연결은 신고 쪽, 반환은 분실물 쪽에서 한다 |
